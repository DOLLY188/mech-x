Closed-Loop Response

The blue curve represents the system output while the dashed reference line represents the desired setpoint.

Proportional Control

The proportional term responds directly to the current error.

P = Kp × e(t)
Increasing Kp generally makes the response faster, but excessive Kp can increase overshoot and oscillation.

Integral Control

The integral term accumulates error over time and helps eliminate steady-state error.

I = Ki × ∫e(t)dt
Increasing Ki can reduce steady-state error but may increase overshoot and settling time.

Derivative Control

The derivative term reacts to the rate of change of the error.

D = Kd × de(t)/dt
Increasing Kd can improve damping and reduce overshoot, although excessive derivative action can make a system sensitive to noise.

Closed-Loop Feedback

Feedback compares the desired reference with the measured output.

e(t) = r(t) − y(t)
The controller continuously uses the error to adjust the plant input.

Engineering Model

Error: e(t) = r(t) − y(t)
PID: u(t) = Kp e(t) + Ki∫e(t)dt + Kd de(t)/dt
First-Order Plant: τ dy/dt + y = Ku
Therefore: dy/dt = (Ku − y) / τ
Euler Integration: y(k+1) = y(k) + Δt · dy/dt
Engineering note: This laboratory uses a simplified first-order plant and numerical Euler integration for educational purposes. Real control systems may require higher order plant models, actuator limits, sensor dynamics, disturbances, filtering, anti-windup and more advanced control techniques.
