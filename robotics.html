Engineering Model

x = L₁ cos(θ₁) + L₂ cos(θ₁ + θ₂)
y = L₁ sin(θ₁) + L₂ sin(θ₁ + θ₂)
cos(θ₂) = [x² + y² − L₁² − L₂²] / [2L₁L₂]
θ₂ = cos⁻¹( [x² + y² − L₁² − L₂²] / [2L₁L₂] )
θ₁ = atan2(y,x) − atan2( L₂ sin(θ₂), L₁ + L₂ cos(θ₂) )
Engineering note: This is a simplified two-dimensional robotic manipulator model. Real industrial robots may have additional joints, three-dimensional motion, joint limits, singularities, actuator dynamics, payload effects and more advanced kinematic and dynamic models.
