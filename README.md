# MECH-X

## Interactive Mechatronics Engineering Laboratory

MECH-X is a browser-based interactive engineering simulation and learning platform designed to bring practical engineering experiments, calculations and visualization into a single environment.

## Engineering Domains

- Mechanical Engineering
- Electrical & Electronics
- Robotics
- Control Systems
- Automotive Engineering
- Mechatronics
- Engineering Calculations
- Engineering Knowledge

## Features

### Engineering Calculators
A collection of practical engineering calculators for common mechanical and electrical problems.

### DC Motor Laboratory
Interactive simulation of a simplified DC motor model.

### Control Systems Laboratory
PID control simulation with system-response visualization.

### Robotics Laboratory
Forward and inverse kinematics for a two-link planar robotic arm.

### Automotive Laboratory
Vehicle dynamics simulation including:

- Engine torque
- Gear ratios
- Aerodynamic drag
- Rolling resistance
- Grade resistance
- Traction
- Acceleration
- Vehicle speed
- Engine RPM

### Mechanical Laboratory
Interactive calculations for:

- Stress
- Strain
- Beam deflection
- Shaft torsion
- Springs
- Gears
- Mechanical power

### Electrical Laboratory
Interactive calculations for:

- Ohm's law
- Electrical power
- Resistors
- Voltage dividers
- RC circuits
- LED resistors

### Knowledge Base
Engineering concepts explained with equations, examples and applications.

### Reports
Generate engineering reports from simulation and calculation results.

## Technology

MECH-X currently uses:

- HTML
- CSS
- JavaScript
- HTML Canvas
- GitHub Pages

No backend is required for the current version.

## Project Goal

The long-term goal of MECH-X is to develop into a broader interactive engineering platform combining simulation, visualization, engineering education and intelligent engineering tools.

## Disclaimer

MECH-X is an educational engineering platform. Simulation results should be independently verified before being used for real engineering design or safety-critical decisions.
